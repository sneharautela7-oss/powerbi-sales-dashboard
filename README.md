# Superstore Sales Dashboard - Power BI

## Overview
This Power BI dashboard analyzes sales, profit, customers, and regional performance using Superstore dataset.

## Tools Used
- Power BI
- Excel

## Key Insights
- West region generated highest sales.
- Consumer segment contributed maximum sales.
- Chairs and Phones were top-selling sub-categories.
- Sales and profit increased during year-end months.
- Standard Class was the most used shipping mode.
